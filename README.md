# legalizai-site

Site institucional da Legalizai — 2 páginas estáticas (HTML/CSS/JS puro, sem build), cada uma seu próprio deploy Vercel:

- `lp/` — landing page institucional (privacidade/termos inclusos). Deploy: `legalizei-lp`.
- `coming-soon/` — página de captura de lista de espera. Deploy: `legalizei-em-breve`.

Extraído do vault `legalizei` (`ux-ui/lp` + `ux-ui/coming-soon`) em 2026-08-03. Fonte de design/decisões continua no vault; este repo é só o código publicável.

`serve.json` na raiz é config de preview local (`npx serve`).
